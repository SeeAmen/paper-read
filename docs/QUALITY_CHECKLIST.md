# 研究质量检查清单

## 新论文登记

- [ ] 路径符合 `<domain>/<organization>/<paper-slug>` 规范。
- [ ] README 的作者、版本、来源、状态和导航完整。
- [ ] `SOURCE.md` 包含权威来源、获取日期和许可信息。
- [ ] `VERSIONS.md` 已建立当前版本基线。
- [ ] `papers/README.md` 已更新。

## 翻译与术语

- [ ] 翻译文件和原文章节可以一一对应。
- [ ] 翻译正文没有混入未标识的解释或个人观点。
- [ ] 术语译法前后一致，并记录首次出现位置和依据。
- [ ] 图、表、公式和引用的编号可回溯到当前论文版本。

## 笔记与结论

- [ ] 核心问题、贡献、机制和限制均有记录。
- [ ] 超出原文的内容使用统一证据标签。
- [ ] 关键结论带有章节、页码、实验或外部来源。
- [ ] 开放问题有当前状态或下一步动作。

## 实验与实践

- [ ] 实验包含环境、步骤、预期、实际结果和失败场景。
- [ ] 代码或命令能在记录的环境中复现。
- [ ] 实践方案写明约束、风险、指标和回滚路径。
- [ ] 尚未验证的内容没有表述为已确认事实。

## 提交前

- [ ] 所有相对链接有效。
- [ ] 没有提交临时文件、密钥、凭据或不允许分发的论文全文。
- [ ] 新的公共术语和主题比较已更新根索引。
- [ ] 论文 README 的状态、版本和最近更新时间准确。
