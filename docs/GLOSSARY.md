# 跨论文公共术语表

| Term | 中文 | 大白话 | 备注 |
|---|---|---|---|
| Harness | 智能体运行框架 / Harness | 模型真正干活时，负责给它工具、上下文、权限、状态和执行环境的那一层 | Agent 领域常用 |
| Runtime | 运行时 | 程序已经跑起来以后，负责管理程序行为的系统 | JVM 也是 Runtime |
| Plugin | 插件 | 可以动态加进系统、给系统增加能力的模块 | 常与生命周期绑定 |
| Effect | 效应 / 副作用 | 程序除了返回结果以外，对外部环境做出的改变 | 如注册 Tool、写文件、开连接 |
| Coeffect | 共效应 | 程序想运行，要求外部环境必须提供什么 | 如权限、服务、依赖 |
| Context | 上下文 | 程序当前可观察和可使用的运行环境 | 不只是一个 Map |
| Revertible Effect | 可逆效应 | 执行时同时产生可由 Runtime 跟踪的 inverse | 做事时顺手留下有效撤销单 |
| Reactive Coeffect | 响应式共效应 | 环境依赖变化时重新判断并协调组件生命周期 | 依赖一变，组件自动停、启或重连 |
| Observational Equivalence | 观察等价 | 公开操作无法区分的两个状态被视为等价 | 内部细节不同，但外部能看到的行为相同 |
| Fiber | 纤程 / 组件实例 | 携带独立生命周期、依赖视图和回滚栈的组件实例 | 同一个组件模板启动出来的一份运行实例 |
| Confluence | 汇合性 | 不同合法执行顺序最终到达等价状态 | 中间顺序不同，最后仍收敛到同一结果 |
